# 🥐 Bakers-Timer

A Flutter application designed for bakers who need precision and reliability. Built with a modern tech stack to ensure your sourdough never over-proofs and your loaves always come out golden.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## ✨ Features

* **Precision Timing:** Multiple concurrent timers for complex baking schedules.
* **Persistent Settings:** Your timer preferences saved locally via `shared_preferences`.
* **Audible Alerts:** Clear, custom audio notifications powered by `audioplayers`.
* **Themed UI:** Beautiful, modern typography using `google_fonts`.

---

## 🛠️ Tech Stack

* **Framework:** Flutter (Android/iOS)
* **State Management:** Riverpod (`flutter_riverpod`)
* **Audio:** `audioplayers` (Migrated for 2025 compatibility)
* **Database:** `shared_preferences` for local persistence
* **Build System:** Gradle 8.14+ with Java 17
